# Guía de Contribución

1. **Crear rama:** Usa nombres descriptivos (`docs/`, `feat/`, `fix/`).
2. **Hacer cambios:** Mantén commits claros y específicos.
3. **Subir y solicitar PR:** Haz `git push` y abre un Pull Request detallando tus cambios.
4. **Buenas prácticas:** Revisa el código antes de enviar y resuelve conflictos.
